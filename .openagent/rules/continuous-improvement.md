# Continuous improvement

- Treat doctor findings, review findings, recoveries, and completed work as candidates for durable guidance.
- Promote stable repo-wide guidance into `.openagent/rules/*.md`.
- Promote early, runtime-facing workflow guidance into `AGENTS.md`.
- Use repo-scoped memory for recurring repo-specific notes that are useful but not yet stable enough to become rules.
- If a finding implies concrete follow-up work, turn it into a task or plan item instead of leaving it as prose only.

## Promotion ladder

1. Capture the finding in a workspace note or repo memory.
2. Decide whether it is local/temporary or stable/reusable.
3. Promote stable guidance into `.openagent/rules/` or `AGENTS.md`.
4. Update tasks, plans, or code when the finding requires execution rather than documentation.
