# Memory policy

- Write repo-scoped memory when a lesson should survive across sessions but is not yet a stable rule.
- Prefer memory for recurring pitfalls, repo-specific setup notes, workflow follow-ups, and investigation breadcrumbs.
- Do not store routine one-off chatter as memory.
- If the same memory is reused or rediscovered repeatedly, promote it into `.openagent/rules/*.md` or `AGENTS.md`.
